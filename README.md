# Tómbola de Sorteo

Tómbola animada para hacer sorteos de números o nombres directamente en el navegador.

**Demo:** https://lorena-concha.github.io/tombola-sorteo/

## Funcionalidades

- Sorteo por **rango** (ej. del 1 al 50) o con una **lista propia** de números o nombres.
- Opción para **sacar la bolita** (no se repite) o permitir repeticiones.
- Tómbola dibujada en Canvas que gira y deja caer la bolita ganadora.
- Historial de bolitas que han salido y botón para reiniciar el sorteo.
- Efectos de sonido (Web Audio) que se pueden desactivar, y confeti al revelar el resultado.
- Modo claro y oscuro automático, diseño responsive y respeto por `prefers-reduced-motion`.

## Stack

HTML, CSS y JavaScript sin dependencias (Canvas API, Web Audio API).

## Uso local

Abre `index.html` en cualquier navegador.
